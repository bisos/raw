* Architecture

- =rawBuild_csu.py= :: shared params --- =freshDeb= (12/13), =platformModel=
  (confined/sysd-priv/sysd-podman), =instance=, =steps=, =noCache=. (=force= was
  REMOVED --- replaced by the =delete= step. =startState=/=endResult=/=endVerify=/
  =endNotify= remain defined but unused --- superseded by =steps=.)
- =rawBuildContainer.cs= :: layered over =bxObjects/bro_dockerfiles=.
  - *Instance/content layer --- =procContainer= (main command).* Takes
    =--steps='[...]'= (a Python-literal list), ast.literal_eval'd, validated
    against =rawBuild_stepTable=, run *serially, fail-fast*. Connect URLs are
    *always* shown at the end. Empty/non-list/unknown step => hard error.
  - *Step registry =rawBuild_stepTable=* (module-level dict). Implemented steps:
    =delete= (instanceDelete stop+rm), =up= (Ps then instanceUp if down),
    =installRawBisos= (exec installRawBisos.sh inside), =verifyUp=
    (containerProc_instanceVerify). Future steps (=verifyRawBisos=, =capRawBisos=,
    =verifyCapRawBisos=) are NOT yet registered --- requesting them hard-errors
    until their handlers are added to the table.
  - =containerPs= :: per-leaf status --- UP (+ connect lines) or NOT up.
  - =allContainersPs= :: docker + podman =ps -a= overview; auto-invoked at the top
    of the =examples= menu so running =-i examples= shows what is up.
  - *Image layer --- =buildImage_rawBisos= (+ =noCache=)*, behind the
    =buildImageExamples= sub-menu. Kept separate from =steps=.
  - =containerPathObtain= :: (freshDeb, platformModel) -> leaf path (+ exists guard).
  - =rawBuild_connectInfoShow(self, platformModel, instancePath)= :: prints runnable
    connect lines --- =vncviewer IP:port # vnc://...=, =ssh -p port bystar@IP #
    ssh://...=, =visitUrl http://IP:port/= (visitUrl TBD). Ports read live from
    =<engine> port <name>=; host IP = =hostname -I= first token; graceful "not
    running" when no ports.
  - Leaf driver: =dockerProc.spcs= / =podmanProc.spcs= chosen by platformModel.
- =rawBuildKvm.cs= :: =buildKvm_rawBisos= --freshDeb; bpoId =pmp_VAG-deb{12,13}_=;

* Key Design Decisions

- *=procContainer= + =steps= pipeline* replaces =buildContainer_rawBisos= AND
  =upContainer_vnc=. One verb; the pipeline expresses intent. Serial, fail-fast.
- *=delete= step replaces the =force= flag* --- intent lives in the pipeline, e.g.
  =["delete","up","installRawBisos","verifyUp"]= vs =["up","verifyUp"]=.
- Param named =steps= (NOT =extent= --- that collides with the cs.Cmnd classHead
  =:extent=). Unknown/empty/non-list steps are a hard error (=problem_usageError=).
- =steps= is the first param that truly needs =ast.literal_eval= (a list). Other
  literal params (=noCache=True=) still arrive as the string ="True"=.
- Connect info (=rawBuild_connectInfoShow=) is ALWAYS shown at pipeline end.
- Two-layer model retained: image (=buildImage_rawBisos=/=buildImageExamples=) stays
  separate from the instance/content =steps= pipeline.
- =containerPs= stays as a distinct read-only status command.
- Sibling CSU imported as =import rawBuild_csu= (=.cs= runs as a script, no parent
  package); csuListProc dblock generator fixed to emit bare =import= for dot-less names.
- =instance= accepted but not part of the leaf path (future: per-instance subdir).
- KVM: single layer, VAG only, {deb12, deb13}. Box: destination IP positional arg.
- =bisos.b= gotcha: =b.subProc.WOpW(invedBy=self)= SHARES the cmnd's one
  =cmndOutcome=; a later =.bash()= overwrites an earlier one's stdout. Always read
  each result inline before the next call. (A docstring note in bisos.b was proposed
  but is currently paused.)
