* Architecture

- =rawBuild_csu.py= :: shared params --- =freshDeb= (12/13), =platformModel=
  (confined/sysd-priv/sysd-podman), =instance=, =steps=, =noCache=. (=force= was
  REMOVED --- replaced by the =delete= step. =startState=/=endResult=/=endVerify=/
  =endNotify= remain defined but unused --- superseded by =steps=.)
- =rawBuildContainer.cs= :: layered over =bxObjects/bro_dockerfiles= and its leaf
  driver =bisos.dockerProc= (=dockerProc.spcs= / =podmanProc.spcs= per leaf,
  chosen by platformModel).
  - *Instance/content layer --- =procContainer= (main command).* Takes
    =--steps='[...]'= (a Python-literal list), ast.literal_eval'd, validated
    against =rawBuild_stepTable=, run *serially, fail-fast*. Connect URLs are
    *always* shown at the end. Empty/non-list/unknown step => hard error.
  - *Step registry =rawBuild_stepTable=* --- every step is one leaf spcs verb:
    | Step           | Leaf verb (bisos.dockerProc)                          |
    |----------------+-------------------------------------------------------|
    | =delete=       | =containerProc_instanceDelete= (stop + rm)            |
    | =up=           | =containerProc_instanceUp= (idempotent: no-op if running) |
    | =down=         | =containerProc_instanceDown= (stop, never rm)         |
    | =rawBisosBase= | =containerProc_exec_installRawBisos=                  |
    | =rawBisosCBMs= | =containerProc_exec_sysCbmFullyMaterialize=           |
    | =verifyUp=     | =containerProc_instanceVerify=                        |
    | =verify=       | =_rawBuild_stepVerify= (docker exec / cp; bisos.capability cbmVerify) |
    Full pipeline: =['delete','up','rawBisosBase','down','up','rawBisosCBMs']=, + ='verify'= for CI
    (the down+up makes groups created by rawBisosBase effective).
  - =rawBuild_isRunning(self, proc, containerName)= :: exact-name running check
    via =<engine> container inspect=. Used by =containerPs=.
  - =containerPs= :: per-leaf status --- UP (+ connect lines) or NOT up.
  - =allContainersPs= :: docker + podman =ps -a= overview; auto-invoked at the top
    of the =examples= menu.
  - *Image layer --- =buildImage_rawBisos= (+ =noCache=)*, behind the
    =buildImageExamples= sub-menu, kept separate from =steps=. That sub-menu
    starts with the *rebuild-all walk*:
    =( cd bro_dockerfiles/debian/13 && ./ftoBranchProc.spcs -i fto_prepare )= ---
    builds every deb13 image in dependency order (confined -> privileged ->
    rootless-sysd). Also shown in the main =examples= menu, each with a
    =--noCache=true= variant (2026-11-23): the walk now passes it on to every leaf
    (=bisos.fileObj= AI-WorkPlan 4.8; before, it was silently dropped and a cached
    build could fail on stale apt lists --- bro_dockerfiles AI-WorkPlan 6.1).
  - =containerPathObtain= :: (freshDeb, platformModel) -> leaf path (+ exists guard).
  - =rawBuild_connectInfoShow= :: runnable connect lines (vncviewer / ssh /
    visitUrl), ports read live from =<engine> port <name>=.
- =rawBuildVerify.py= :: =collect(target, runAsBystar, fetch, start, steps)=: fullyVerify on the

* Key Design Decisions

- *=procContainer= + =steps= pipeline* replaces =buildContainer_rawBisos= AND
  =upContainer_vnc=. One verb; the pipeline expresses intent. Serial, fail-fast.
- *=delete= step replaces the =force= flag* --- intent lives in the pipeline.
- *Every step goes through a leaf spcs verb* --- no raw =docker exec= in this
  repo; scripts that run inside the container live in =common/raw-bisos/=.
- *Container identity is the exact container name, never a substring.* The leaf
  name is a prefix of sibling leaves (=bisos_deb13-sysd= vs =bisos_deb13-sysd-2=)
  and of the shared image (=bisos_deb13-sysd:latest=). Grepping =ps= output for
  it made =up= skip starting the leaf when =-2= was running (fixed 2026-11-03).
- *Inside the container, bystar commands need =bash -ic=* --- bystar's =.bashrc=
  returns early for non-interactive shells, before PATH (pipx/bisos3 bin) and nvm.
  Handled inside =sysCbmFullyMaterialize.sh=.
- *Image rebuild never touches instances* --- =fto_prepare= / =containerProc_imageBuild=
  only build; instances keep running on the old (untagged) image until
  =delete=+=up= or =fto_reMaterialize=. Walk from =debian/<N>/=, not =debian/=
  (its =fto_effectiveBranches= is empty).
- Param named =steps= (NOT =extent= --- collides with the cs.Cmnd classHead =:extent=).
- Two-layer model: image (=buildImage_rawBisos=/=buildImageExamples=) separate from
  the instance/content =steps= pipeline. =containerPs= stays read-only status.
- Sibling CSU imported as =import rawBuild_csu= (=.cs= runs as a script).
- =instance= accepted but not part of the leaf path (future: per-instance subdir).
- KVM: single layer, VAG only, {deb12, deb13}. Box: destination IP positional arg.
- =bisos.b= gotcha: =b.subProc.WOpW(invedBy=self)= SHARES the cmnd's one
  =cmndOutcome=; a later =.bash()= overwrites an earlier one's stdout. Read each
  result inline before the next call.
