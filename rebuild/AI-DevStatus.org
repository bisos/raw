* Architecture

- =rawBuild_csu.py= :: shared params via commonParamsSpecify --- =freshDeb=
  (12/13), =platformModel= (confined/sysd-priv/sysd-podman), =instance=, =force=,
  =noCache=, plus placeholders (=startState=, =endResult=, =endVerify=, =endNotify=).
- =rawBuildContainer.cs= :: layered over =bxObjects/bro_dockerfiles=. Two layers:
  - Instance layer --- =buildContainer_rawBisos= (main): resolve leaf via
    =containerPathObtain= -> Ps -> (force) delete -> up -> exec installRawBisos.
  - Image layer --- =buildImage_rawBisos= (+ =noCache=), behind the
    =buildImageExamples= sub-menu to keep the main menu uncluttered.
  - =containerPathObtain= :: maps (freshDeb, platformModel) to the leaf path and
    verifies it exists.
  - Each leaf is driven by its planted CS: =dockerProc.spcs= (docker) /
    =podmanProc.spcs= (podman, sysd-podman) selected by platformModel.
- =rawBuildKvm.cs= :: =buildKvm_rawBisos= --freshDeb; bpoId =pmp_VAG-deb{12,13}_=;
  intended to drive =sysCharGuestMaterialize.sh= (placeholder body).
- =rawBuildBox.cs= :: =buildBox_rawBisos= --freshDeb + destination IP as positional
  arg; intended to drive =sysCharBoxMaterialize.sh= (placeholder body).
- Cross-repo fix applied :: =bisos.dockerProc= containerProc_exec_installRawBisos
  (in bisos-pip/dockerProc) --- run as =-u bystar= (not root), drop =-it=
  (non-interactive), and propagate exit status (was masked as always-Success).

* Key Design Decisions

- Two-layer container model (image vs instance) --- different change cadences;
  =force= means only "delete existing instance", not "rebuild image".
- Image construction kept out of the main workflow (behind =buildImageExamples=).
- Param values use Python-literal syntax (=True=, not ='t'=). Note: PyCS delivers
  CLI values as strings, so code compares to ="True"=.
- Sibling CSU imported as =import rawBuild_csu= (not =from . import=) because =.cs=
  files run directly as scripts (no parent package); csuList entry is =rawBuild_csu=.
  Fixed the =csuListProc= dblock generator to emit bare =import= for dot-less names.
- =instance= is accepted but not part of the container path (future: per-instance
  subdir).
- KVM: single layer, VAG only, {deb12, deb13}. Box: destination IP is a positional
  argument, {deb12, deb13}.
